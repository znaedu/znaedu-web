Parcours académique :
Le catalogue est conçu pour descendre progressivement de l'échelle nationale jusqu'au contenu pédagogique : pays → système éducatif → niveau → cycle → classe/année → filière/série → discipline → programme → version du programme → thème → sous-thème → compétence → cours → exercice → quiz → correction → remédiation.

Les niveaux, classes, filières et disciplines scolaires doivent provenir du catalogue académique de Supabase. Ils ne sont pas récupérés dans le catalogue général de Mondo Quiz.
