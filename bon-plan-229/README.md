# Bon Plan 229

Bon Plan 229 est une plateforme destinée à permettre aux utilisateurs de publier des annonces, proposer des produits ou services, rechercher des offres, effectuer des commandes et suivre leurs opérations.

## Fonctionnalités prévues

- Publication d'annonces
- Recherche d'annonces
- Catégories
- Profils utilisateurs
- Produits et services
- Commandes
- Suivi des commandes
- Packs de visibilité
- Boost des annonces
- Paiements
- Commissions
- Suivi financier
- Gestion des vendeurs
- Gestion des acheteurs
- Gestion administrative
- Traçabilité des opérations

## Structure

- `index.html` : interface principale
- `style.css` : styles de l'interface
- `app.js` : logique côté navigateur
- `database.js` : structure de données
- `server.js` : serveur
- `package.json` : configuration Node.js
- `.env.example` : variables d'environnement
- `.gitignore` : fichiers exclus de Git
- `README.md` : documentation
